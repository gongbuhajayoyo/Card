# 내 카드 관리

카드별로 이번 달(1일~말일) 실적 목표까지 **더 쓸 수 있는 금액**을 보여주는 휴대폰용 웹앱입니다.

- 홈: 카드마다 현재 사용금액만 입력
- 설정: 실적 구간(1·2·3차), 목표 구간, 고정지출, 메모, 카드 순서·색상, 백업
- 목표에 도달했거나 넘긴 카드는 홈에서 맨 아래로 이동 (사용금액 초기화 시 원래 순서로 복귀)
- 데이터는 이 기기 브라우저에만 저장됩니다. 설정 → 백업으로 옮길 수 있어요.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 화면 전체 |
| `manifest.webmanifest` | 설치 시 앱 이름·아이콘·실행 화면 색 |
| `icons/` | 앱 아이콘 |
| `sw.js` | 오프라인에서도 열리게 하는 캐시 |
